## 跳过训练直接复现 / Reproduce Without Retraining

挂载权重后，无需 100 epoch 训练即可复现预测 (见 SUBMISSION.md 第 6 节)：
With the checkpoint mounted, reproduce predictions without 100-epoch training
(see SUBMISSION.md Section 6):

```bash
docker run --gpus all \
  -e DATA_ROOT=/data/imagenet \
  -v /host/imagenet:/data/imagenet \
  -v /host/best.pth:/workspace/checkpoints_full_mixcut/best.pth \
  embodied-ai \
  bash -c 'sed "s#^  root:.*#  root: ${DATA_ROOT:-/data/imagenet}#" \
    configs/imagenet_resnet50_full_mixcut.yaml > configs/_runtime.yaml && \
    python scripts/predict.py --checkpoint checkpoints_full_mixcut/best.pth \
      --config configs/_runtime.yaml --output submit/result.csv && \
    python scripts/validate_csv.py --csv submit/result.csv'
```
